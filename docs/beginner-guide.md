# Beginner guide (v7)

The v6 beginner guide (ports, llama.cpp setup, WSL2 install) is obsolete —
v7 is a single double-click flow.

**Just do this instead:**

1. Read [QUICK-START.md](../QUICK-START.md) (2 minutes).
2. If something goes wrong, run `check.bat` / `check.sh` and read
   [OFFLINE-GUIDE.md](../OFFLINE-GUIDE.md) "Gotchas".
3. The full story of what changed and why: [CHANGELOG.md](../CHANGELOG.md).
